## Windows 11 Safe Config
- All registry tweaks included in Zoicware. [Read More](https://github.com/zoicware/ZOICWARE/blob/main/registrytweaks.md)
- Install essential packages such as C++, DirectX and .NET 3.5.
- Disable telemetry.
- Fully debloat Windows, leaving only Paint, Photos, Notepad, Terminal, Store and Xbox.
- Apply a black Windows theme.
- Disable the security warning when opening downloaded files.
- Set the mouse and sound schemes to none.
- Remove the network icon from File Explorer.
- Disable PowerShell logging.
- Enable faster shutdown and restart.
- Use a more accurate time server for the system clock.
- Add `Take ownership` to the context menu.
- Remove `Add to Favorites`, `Customize this folder`, `Give access to`, `Open in Terminal`, `Restore previous versions`, `Print`, `Send to`, `Share`, `Troubleshoot compatibility` and `Include in library` from the context menu.
- Set most services to manual.
- Show all taskbar tray icons.
- Remove Quick Settings tiles.
- Disable Notepad tabs and the rewrite feature.
- Remove ads from the Settings app.

## Windows 11 Recommended Config
**Same as above, plus the following added features:**
- Remove scheduled tasks.
- Disable Defender.
- Disable Windows Update.
- Disable unnecessary services.
- Remove Store and Xbox.
- Import a custom power plan.
- Remove all other power plans.
- Remove the Game Bar popup.
- Hide the user tile in the Start menu.
- Import a modern cursor scheme.
- Apply dark accents.
- Remove mouse acceleration on the desktop.
- Add new file types and Snipping Tool to the context menu.
- Remove `Extract All` from the context menu.
- Add the Windows 10 Recycle Bin icon.
- Add the Windows 10 Snipping Tool.

## Windows 11 Extreme Config
**Same as above, plus the following added features:**
- Block Razer and ASUS download servers.
- Enable No GUI Boot.
- Disable BitLocker device encryption.
- Enable the Windows 10 File Explorer ribbon.
- Set the background mouse throttle to 50 Hz.
- Enable the 24H2 Start menu.

## How to Use
1. Download the latest version of Zoicware from the [releases](https://github.com/zoicware/ZOICWARE/releases) page.
2. Download your desired config.
3. Run Zoicware and navigate to `Utilities` > `Import/Export Config`.
4. Choose the location of the config file and click `Run Tweaks`.
